# Client Requirements Document

* Project: Learner Support Portal
* Client: SkillsTrack Training Centre


##  Problem Statement
* Learners currently record goals, tasks, support bookings, and progress in separate documents and messages. Assessors struggle to track outstanding work, identify learners needing support, and monitor progress effectively.


##  Functional Requirements

* The portal must allow registered users to:
* Manage learning tasks (create, update, mark complete).
* Book support sessions with assessors.
* Review progress (visual progress tracking for learners and assessors).
* Access learning resources (documents, links, guides).
* Play a short coding game for practice.


## User Roles

* Learners:
* Register/login securely.
* Manage personal tasks and goals.
* Book support sessions.
* Track their own progress.
* Access resources and coding game.

* Assessors:
* View learner progress dashboards.
* Identify outstanding tasks.
* Track which learners need support.
* Manage support bookings.


## Technical Requirements

* Frontend: JavaScript for application logic.
* Backend/Database: Firebase for authentication, data storage, and hosting.
* Platform: Browser-based (desktop and mobile accessible).
* Security: User authentication, secure data handling, role-based access.


##  Constraints

* Must be lightweight and user-friendly.
* Must integrate seamlessly with Firebase services.
* Limited to short occupational programmes (not a full LMS).


##  Success Criteria

* Learners can manage all learning activities in one portal.
* Assessors can easily see outstanding work and learner progress.
* Portal improves efficiency compared to scattered documents/messages.
* Secure, reliable, and accessible system.
