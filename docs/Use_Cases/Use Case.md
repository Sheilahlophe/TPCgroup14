# Use Cases

## Learner Use Cases

- Learner registers an account.

- Learner logs into the system.

- Learner views the dashboard.

- Learner creates a task.

- Learner views tasks.

- Learner searches for a task.

- Learner filters tasks by status.

- Learner filters tasks by priority.

- Learner edits a task.

- Learner marks a task as completed.

- Learner deletes a task.

- Learner views task progress.

- Learner prints task progress.

- Learner books a support session.

- Learner views support booking status.

- Learner views learning resources.

- Learner plays the JavaScript quiz game.

- Learner logs out.


## Assessor Use Cases

- Assessor logs into the system using provided login details.

- Assessor views the assessor dashboard.

- Assessor views learner support bookings.

- Assessor updates the status of a support booking.

- Assessor adds learning resources.

- Assessor views learning resources.

- Assessor deletes learning resources.

- Assessor views the number of learners.

- Assessor logs out.
